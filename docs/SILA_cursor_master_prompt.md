# 1. Концепция бренда

## Название

**SILA**

SILA — премиальная студия цифровой архитектуры для бизнеса. Студия создаёт сайты, интернет-магазины, приложения, интерфейсы и визуальную архитектуру бренда. Клиент приходит не за отдельной страницей, а за цельной оболочкой бизнеса: формой, ритмом, стилем, доверием и понятной цифровой точкой входа.

- B2B.

- Основной рынок: Россия.
- Клиент ценит время, качество коммуникации и профессиональное ведение проекта.

- Ему нужен партнёр, который понимает бизнес, способен предложить сильное визуальное решение и довести продукт до завершённого состояния.

**SILA создаёт не сайты. SILA создаёт форму бизнеса.**

## Тон коммуникации

- спокойный;
- взрослый;
- точный;
- премиальный;
- лаконичный;
- без канцелярита;
- без инфобизнес-лексики;

# 2. Главная дизайн-идея

Создай тёмный premium-minimalist сайт с аккуратной этнической пластикой. Этно-стиль должен ощущаться не как декоративный орнамент, а как визуальная память: ритм, вязь, знаки, тонкие линии, характерная типографика, едва заметные паттерны и символические композиции.

Сайт должен сочетать:

- монохромную digital-эстетику;
- прозрачные стеклянные плоскости;
- мягкие cinematic-анимации;
- редкие тёплые акценты;
- крупную типографику;
- контролируемое отрицательное пространство;
- ощущение дорогого интерфейсного объекта;
- лёгкий контраст между современной цифровой средой и этническими мотивами.

## Визуальные референсы

Используй приложенные изображения как направление, а не как шаблон для прямого копирования.

### Из референсов необходимо перенять

1. **Тёмный фон и полупрозрачные панели**
  Чёрные и графитовые поверхности, тонкие светлые границы, лёгкий blur, приглушённые блики, эффект стекла без чрезмерной «мыльности».
2. **Один редкий, но выразительный акцент**
  Используй глубокий ember-red / тёмный киноварный оттенок для свечения, активных состояний, небольших линий, точек, маркеров и CTA. Акцент не должен превращаться в массивную цветную заливку.
3. **Интерфейсная архитектура**
  Аккуратные модульные сетки, компактные контролы, овальные элементы, тонкие рамки, ясная типографическая иерархия.
4. **Cinematic depth**
  Небольшая глубина сцены, слои, медленно движущиеся фоновые элементы, мягкий параллакс, подсвеченные края стеклянных плоскостей.
5. **Минимализм без пустоты**
  Каждый блок должен иметь визуальный смысл. Не добавляй декоративные элементы без функции.

### Не копировать

- структуру конкретных экранов;
- чужие надписи;
- чужие карточки продуктов;
- персонажей и изображения роботов;
- точное расположение элементов;
- UI чужих сервисов.

# 3. Ограничения визуального языка

## Главный запрет

**Не используй плотные цветные заливки для карточек и секций.**

Большинство элементов должны быть:

- прозрачными;
- полупрозрачными;
- контурными;
- стеклянными;
- монохромными;
- отделёнными тонкими линиями;
- визуально лёгкими.

Белый и акцентные цвета применяются как:

- текст;
- рамка;
- тонкая линия;
- небольшая точка;
- маркер;
- hover-состояние;
- рассеянное свечение;
- декоративный символ;
- микродеталь интерфейса.

Не превращай сайт в неоновый cyberpunk. Не используй кислотные градиенты, массивные glow-эффекты, чрезмерную размытость и случайные 3D-объекты.

# 5. Типографика

## Заголовки

Используй предоставленный локальный шрифт **Satyr SP Basic** для крупных заголовков и акцентных слов. Подключи его через `next/font/local`.

Создай файл:

```text
app/fonts.ts
```

Подключение должно быть локальным и централизованным.

Для отдельных крупных декоративных слов или знаков используй **Вязь** как дополнительный этнический слой. Если файл шрифта Вязь не предоставлен, создай аккуратную переменную-заглушку и пометь место подключения комментарием `TODO: add local Vyaz font file`. До загрузки файла используй Satyr как fallback. Не загружай внешний неизвестный font CDN.

## Основной интерфейсный шрифт

Используй **Manrope** через `next/font/google` или локальный fallback. Он должен применяться для:

- абзацев;
- кнопок;
- навигации;
- метаданных;
- форм;
- подписей;
- карточек.

## Иерархия

- H1: крупный, выразительный, с контролируемым межстрочным расстоянием.
- H2: короткие композиционные заголовки.
- H3: функциональные заголовки карточек.
- Body: хорошо читаемый, компактный, с шириной строки 55–72 символа.
- Overline: uppercase, увеличенный tracking, малый размер.

Не используй слишком много размеров шрифта. Система должна быть строгой.

# 6. Технологический стек

Создай проект на:

- Next.js с App Router;
- React;
- TypeScript;
- Tailwind CSS;

Сохраняй архитектуру лёгкой. Сайт должен выглядеть эффектно за счёт композиции, типографики, света, линий, прозрачности и анимационного ритма, а не за счёт тяжёлых зависимостей.

# 14. Анимации

## Общий принцип

Анимация должна поддерживать атмосферу, а не отвлекать от содержания. Сайт должен ощущаться живым даже при спокойном темпе.

## Использовать

- плавный scroll через Lenis;
- reveal анимации при появлении блоков;
- opacity + translateY;
- clip-path только в отдельных крупных заголовках;
- мягкий blur-to-sharp;
- stagger для строк и карточек;
- аккуратный parallax;
- sticky-секции;
- loop-слайдер кейсов;
- subtle magnetic hover для важных CTA на desktop;
- hover-подсветку рамки;
- переходы между страницами;
- минимальную реакцию декоративных символов на движение мыши.

## Не использовать

- перегруженные scroll-jacking эффекты;
- резкие скачки;
- тяжёлые particle systems;
- чрезмерный motion;
- анимацию каждого текста;
- бессмысленный бесконечный motion;
- анимации, мешающие чтению;
- эффекты, ухудшающие Core Web Vitals.

## Accessibility

Для `prefers-reduced-motion: reduce`:

- отключи плавный scroll;
- убери parallax;
- сократи duration;
- отключи loop auto-play;
- оставь функциональность интерфейса полностью доступной.
